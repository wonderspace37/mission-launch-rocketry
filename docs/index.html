Current build

Yellow Jacket

Our two-stage high-power rocket. The H219T booster burns for about a second, the stages separate, and the H100W sustainer lights in flight four seconds after launch. Dual-deploy recovery, independent avionics bay.

Design rework in progress (Nov 2026). The baseline review found the stack is under one caliber stable off the rail in a light crosswind, and the CAD and OpenRocket fins don't match. Read the review →

Version control

How we work

One file per design, edited in place. No more rocket (3).ork: git remembers every version.

Branch

Start a branch named after the change, like fin-resize.

Change one thing

Edit the .ork, export new CAD, or add a sim result.

Commit with a reason

Say why, not just what: the history is for whoever reads it next year.

Open a pull request

Someone else looks it over before it merges to main.

The full guide is in CONTRIBUTING.md.
